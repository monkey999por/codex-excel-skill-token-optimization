# 4. チェックスキルの一覧と適用条件

Copilot 等に次のブロックをそのまま貼り付ける。

```text
このリポジトリを読み取り専用で調査してください。編集・スクリプト実行・本番データの閲覧はしないでください。
各チェック用 skill について、名前、対象仕様書、起動条件、読む参照ファイル、呼ぶスクリプト、AI が判断する部分、出力先、完了条件を表にしてください。共通規則と種類固有の規則も分けてください。
SKILL.md の記述と実際の参照・呼出しが一致しない箇所は明記してください。各行に根拠のファイル:行を付け、skill が見つからない場合は探索した場所を記してください。
```
