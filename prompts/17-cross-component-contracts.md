# 17. コンポーネント間の暗黙の契約

Copilot 等に次のブロックをそのまま貼り付ける。

```text
このリポジトリを読み取り専用で調査してください。編集・スクリプト実行・本番データの閲覧はしないでください。
skill、script、設定、ファイル形式の間にある暗黙の契約を洗い出してください。特に、固定のファイル名、ディレクトリ、行順、列順、文字コード、シート名、終了コード、標準出力の形式、前段の完了条件に依存する箇所を探してください。
各契約について「書き手」「読み手」「破れたときの挙動」「自動検証の有無」を表にし、根拠のファイル:行を付けてください。未確認の依存は仮説と明記してください。
```
