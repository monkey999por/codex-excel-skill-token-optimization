# 00. Microsoft Copilotアプリの本文アクセス確認

**他の質問より先に**実行する。通常チャットなら関連ファイルを明示添付する。Codeタブがある場合のみ、許可済みの調査用ローカルコピーを開く。ZIPリンクだけを渡す方法は使わない。

```text
私は本番リポジトリの調査用コピーを調べたいです。まず、このMicrosoft Copilotアプリの今回のチャットで、実際に本文を読める範囲だけを確認してください。システムの説明やREADMEの要約はまだ不要です。
【絶対ルール】添付表示・フォルダー名・目録上の名前だけで本文を読めたとみなさない。使えない検索・ファイル閲覧・コード実行機能を使ったふりをしない。読むだけで、編集、コマンド実行、ネットワーク接続はしない。
1. 今使っているのは通常チャット、OneDrive内のCopilot、Codeタブのどれですか。分からなければ不明と答えてください。今回明示的に参照できるファイル・フォルダーを示してください。
2. SKILL.mdを1件、関連scriptを1件、設定またはテストを1件、実際に本文を開いて確認してください。各々について、原本相対パスと本文にある非機密の見出し・関数名・設定キーを1つ示してください。表示できないものは「名前だけ確認」「未確認」に分けてください。行番号が見えなければ作らないでください。
3. 目録またはフォルダーが渡されている場合、目録上の候補数と、今回本文を確認できたファイル数を分けてください。フォルダー全件にアクセスできるか、数件を選択しただけかも分けてください。
4. 最後に「このテーマを深掘り可能」「一部だけ可能」「追加の原本ファイルが必要」のいずれかを選んでください。あなた自身が次の調査対象を判断し、必要なディレクトリ一覧や原本ファイルを相対パスで、優先順・理由・本文で確認する点とともに最大5件要求してください。パスが分からなければ、まずどの階層の一覧が必要か具体的に要求してください。受け取った後は本文から呼出し先・設定・テストを見つけ、必要な対象を追加で要求して深掘りを続けてください。読めていない範囲の結論は出さないでください。
秘密値や本番データ本文は表示しないでください。
```
