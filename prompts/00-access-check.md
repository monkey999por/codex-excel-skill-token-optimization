# 00. ZIPの展開と閲覧範囲の確認

**他の質問より先に**、ZIPをアップロードした同じチャットで実行する。ChatGPTはコード実行でZIPを展開し、**中の全ファイルを自分で一覧・検索・閲覧できる**。ここでは「本当に全件を展開できたか」「どこが読めない（バイナリ・巨大・文字化け）か」を最初に確定させる。ZIPの作り方は[ChatGPT利用ガイド](chatgpt-zip-usage.md)を参照。

```text
アップロードしたZIPは、本番リポジトリの調査用コピーです。システムの説明やREADMEの要約はまだ不要です。まず、このZIPを調査できる状態かだけを確認してください。
【絶対ルール】コード実行は、ZIPの展開・ファイル一覧・検索・本文表示（行番号付き）・件数集計だけに使う。リポジトリのscript・テストの実行、パッケージのインストール、ネットワーク接続、ファイル編集はしない。結果は実際に実行した処理の出力に基づいて答え、実行していない処理の結果を作らない。秘密値や実データ本文は表示しない。
1. ZIPを作業ディレクトリへ展開し、展開先のパスを示してください。ZIP内のエントリ数と展開後のファイル数、合計サイズ、第一階層の構成、拡張子別の件数を示してください。両者の件数が合わない場合は差分を列挙してください。
2. 展開できなかったファイル、UTF-8等で読めないテキスト、バイナリ（xlsx等）、極端に大きいファイルを分けて列挙してください。中身は開かずに、相対パスとサイズだけ示してください。
3. 機密を含み得るパス名（.env、鍵、認証情報、実データらしきExcel/CSV、ログ、生成物）があれば、内容を開かずに相対パスだけ警告してください。
4. SKILL.mdを1件、それが参照するscriptを1件、設定またはテストを1件選び、実際に本文を開いてください。各々について相対パス、実際の行番号、非機密の見出し・関数名・設定キーを1つずつ示してください。
5. SKILL.md、実行入口（CLI・main・ジョブ定義等）、テスト、CI設定の候補を検索し、それぞれの件数と代表的な相対パスを示してください（ここではまだ本文の深掘りは不要）。
最後に「全件を調査可能」「一部に制約あり（内容）」「ZIPの作り直しが必要（理由）」のいずれかで判定してください。作り直しが必要な場合は、何を含める・除外すべきかを具体的に示してください。
```

**合格の目安**：件数が一致し、4で実在する行番号と識別子が出ること。件数不一致・展開失敗・「展開しました」とだけ答えて出力を示さない場合は、ZIPを作り直すか同じ指示を再送する。
