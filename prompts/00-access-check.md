# 00. OneDrive上のZIP・ファイルへのアクセス確認

**他の質問より先に**、Microsoft Copilotアプリの同じチャットで実行する。ZIPまたは展開済みフォルダーをOneDriveから参照・添付してから、次のブロックを貼り付ける。

```text
私はOneDriveに置いた本番リポジトリのコピーを調査したいです。まず、このチャットで実際に何を読めるかだけ確認してください。READMEの要約やシステムの説明はまだ不要です。
【絶対ルール】ZIP名・フォルダー名・添付表示だけで中のファイルを読めたとみなさないでください。存在しない検索・解凍・コード実行機能を使ったふりをせず、ファイル内容を確認できたものと名前だけ見えるものを分けてください。
1. 添付・参照できた対象の名前、形式、アクセス可能な範囲を示してください。ZIP内部の相対パスを列挙できるか、個別ファイル本文を開けるかを分けて回答してください。
2. 可能なら、SKILL.mdを1件、関連scriptを1件、設定またはテストを1件選び、相対パスと、そのファイル内に実際にある非機密の見出し・関数名・設定キーを1つずつ示してください。行番号が見えないなら作らないでください。3種類のうち見つからないものは未確認としてください。
3. この環境にZIPを作業用コピーとして安全に展開する機能が実際にあり、利用が許可されている場合だけ、元ZIPと本番リポジトリを変更せず展開してください。できない場合は無理に進まず、私がローカルで解凍してOneDriveへ置くべきファイル・フォルダーを優先順に教えてください。
4. 最後に「このまま深掘り可能」「一部だけ可能」「解凍・再添付が必要」のいずれかを選び、今回の確認で読めなかった範囲を示してください。全体を読めていないなら、リポジトリ全体に関する結論は出さないでください。
本番データ本文・秘密値は表示しないでください。
```
