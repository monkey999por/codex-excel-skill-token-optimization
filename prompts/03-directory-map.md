# 3. ディレクトリ構造と役割

リポジトリのZIPをアップロード済みのChatGPTチャットに、次のブロックをそのまま貼り付ける。

```text
【前提・絶対ルール】このチャットにアップロード済みのZIP（本番リポジトリの調査用コピー）だけを対象にする。まだ展開していなければコード実行で作業ディレクトリへ展開し、展開済みならそれを使う。ZIPの全ファイルを自分で一覧・検索・閲覧できるので、ユーザーにファイルを求めず、必要なものは自分で開く。結論に使うファイルは必ず本文を開き、ファイル名や記憶だけで語らない。展開済みファイルが見つからない（セッション切れ等）場合はそう伝えて再アップロードを求め、過去の回答の記憶で埋めない。
【調査・絶対ルール】README・docs・コメントの要約だけで結論を出さない。ZIP全体をファイル名・識別子・skill名・設定キー・ファイル名リテラルで横断検索し、関連SKILL.md、ソースコード、設定、テスト、CIの本文を読み、入口→呼出し元・先→入出力→検証を追い、反例も探す。一つ読んだら、そこから見つかった呼出し先・参照ファイル・テストを続けて開き、問いが解けるまで自走で深掘りする。
【実行範囲・絶対ルール】コード実行はZIPの展開・ファイル一覧・検索・本文表示（行番号付き）・件数集計だけに使う。リポジトリのscript・テストの実行、パッケージのインストール、ネットワーク接続、ファイルの編集はしない。
【根拠ルール】実装に関する結論は「ZIPルートからの相対パス:行番号」で裏付ける。行番号は展開したファイルから実際に取得したものだけを使い、作らない。文書だけの事項は「文書上の記述」、実装で確認できない事項は「推測・未確認」と明記する。「存在しない」「全て」と言う場合は、検索した語・対象範囲・ヒット件数を示す。ZIPに含まれない情報（除外した秘密・実データ、履歴、外部システム、運用ルール）は「ZIP外・要確認」に分け、確認先を示す。後述の「ファイル:行」指定もこのルールに従う。
【回答の冒頭】今回本文を開いた相対パスの一覧と、検索で見つかったが開いていない関連ファイル（あれば理由）を先に示す。秘密値や実データ本文は表示しない。
このリポジトリを読み取り専用で調査してください。
新規参加者が先に読むべき主要ディレクトリとファイルだけを、役割付きの簡潔なツリーで示してください。skills、scripts、設定、参照資料、テスト、入力例、生成物、CI等を探し、存在しないものは作り足さないでください。
各項目について「どこから参照・呼び出されるか」と根拠のファイル:行を示してください。自動生成物や機密情報を含み得る場所があれば、内容を表示せず場所と取扱い上の注意だけ記してください。
```
